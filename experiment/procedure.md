<b>Launching the Simulation:</b><br>
1. Install the VR Vehicle Simulator application on the headset.<br>
2. Connect and calibrate VR headset and controllers (or steering wheel setup, if available).<br>
3. Select the vehicle type and environment (city road, highway, or test track).<br>
4. Adjust headset for comfort and ensure controls are working.<br><br>

<b>Working of the Simulation:</b><br>
1. Start the vehicle using the VR interface.<br>
2. Practice steering, acceleration, and braking using VR controllers.<br>
3. Navigate through different road environments:<br>
   * Straight roads<br>
   * Turns and curves<br>
   * Slopes and uneven terrains<br>
   
4. Observe effects of speed on braking distance and stability.<br>
5. Complete given driving tasks such as lane changing, obstacle avoidance, and parking.<br>
6. Record performance data (speed, accuracy, number of collisions).<br>
7. Analyze results to understand safe driving practices.
