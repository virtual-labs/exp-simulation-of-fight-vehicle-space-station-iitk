<b>Note: </b> This is a VR-based experiment; in the simulation; you can learn from scratch how to download the APK and use VR, while the Procedure section explains the actual lab experiment steps as performed in the Virtual Reality (VR) Lab. <br><br>


| **Step** | **Actual Lab Procedure (Physical Test Track)** | **Virtual Reality (VR) Lab Procedure (Simulation)** |
|-----------|-----------------------------------------------|----------------------------------------------------|
| **1. Preparation** | The test driver secures safety gear (helmet, harness). Vehicle pre-checks are conducted. Tire pressure and fuel load are set to precise, verifiable levels. | The user/driver calibrates the physical controls (wheel/pedals) to the virtual vehicle. Virtual parameters (e.g., road friction, weather) are selected from the system menu. |
| **2. Full Throttle Launch** | The driver stages the car, shifts into drive, and applies full throttle from a stop to assess power and acceleration. | The user applies the simulated accelerator pedal to perform a full throttle launch. The virtual dashboard shows real-time speed (MPH/KMH) and RPMs. |
| **3. Dynamic Handling** | The driver navigates a winding road section or slalom course, actively managing the physical steering wheel and monitoring real G-force readings. | The user steers through the virtual city and winding roads. The physics engine calculates and displays virtual G-forces and handling response on the data overlay. |
| **4. Emergency Braking** | At a specific marker and speed (e.g., 80 km/h), the driver executes a hard brake application to trigger the Anti-lock Braking System (ABS) and measure the stopping distance. | The user hits the virtual brake pedal completely to simulate an emergency stop. The system logs the virtual stopping distance and deceleration rate. The car halts smoothly and safely (as mentioned in the video). |
| **5. ADAS Simulation** | A physical obstacle (e.g., car or pedestrian dummy) is placed in the lane. The vehicle's collision warning (Radar/Lidar) is tested for correct detection and auto-braking activation. | The Red Overlay (shown in the video) appears, representing the virtual sensor field (Radar/Lidar). The system logs the virtual sensor's detection range and precision when approaching a virtual obstacle. |
| **6. Data Collection** | Technicians download physical data logs (speed, braking pressure, G-forces) from the onboard vehicle computer for analysis. | The VR system automatically generates a Simulation Report containing virtual speed, RPM, gear shifts, driver input fidelity, and ADAS event logs. |
